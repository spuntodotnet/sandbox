---
title: Spunto Cloud
description: The same engine, hosted.
---

[Spunto Cloud](https://spunto.net) runs this engine on its own machines: the same microVMs, the same
pause that keeps the memory, the same forks — without a machine to run. Sandboxes are billed by the
minute they run; a paused one stops the meter.

It adds what a platform adds: an API and an MCP server for agents, a dashboard, projects
(devcontainer-compatible environments), tasks delegated to coding agents, shared builds, teams.

Use Spunto Sandbox when you want your sandboxes on your hardware; Spunto Cloud when you would rather
not have hardware.
